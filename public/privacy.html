Политика конфиденциальности

Мы серьёзно относимся к защите персональных данных. Этот документ объясняет, какие данные мы собираем и как их используем.

ИИН не сохраняется

Введённый вами ИИН используется только для разового запроса к API и не записывается в базу данных.

1. Кто мы

ZakonExpert — юридическо-консалтинговая компания, оказывающая услуги по снятию арестов, ограничений и сопровождению исполнительных производств в Республике Казахстан. Сайт расположен по адресу zakonexpertt.kz.

2. Какие данные вводит пользователь

На сайте есть форма проверки по ИИН. Пользователь вводит свой ИИН (индивидуальный идентификационный номер) из 12 цифр. Никакие другие персональные данные (ФИО, адрес, дата рождения, номер телефона) в форме проверки не запрашиваются и не собираются.

3. Цель обработки ИИН

ИИН используется исключительно для отправки запроса к публичному API открытых данных eGov Казахстана (opendata.egov.kz) с целью получения информации об исполнительных производствах. Результат отображается пользователю на экране.

4. Хранение и передача данных

  • ИИН не сохраняется в нашей базе данных и не записывается в файлы.
  • В служебных логах сервера ИИН маскируется: хранятся только первые 4 цифры (например, 1234********).
  • ИИН не передаётся третьим лицам — кроме официального API eGov Казахстана для выполнения проверки.
  • Данные API eGov обрабатываются исключительно в рамках действующего законодательства Республики Казахстан.

5. Файлы cookie и аналитика

Сайт может использовать технические cookie для обеспечения корректной работы. Мы не используем сторонние системы аналитики (Google Analytics, Яндекс.Метрика и т.п.), которые бы собирали и передавали персональные данные третьим лицам.

6. Безопасность

Передача данных между вашим браузером и нашим сервером осуществляется по защищённому протоколу HTTPS. Сервер защищён заголовками безопасности (Helmet). Мы не храним ИИН и минимизируем обработку персональных данных.

7. Ваши права

Поскольку мы не храним ИИН и персональные данные в базе данных, запросы на удаление данных технически не применимы. Тем не менее, если у вас есть вопросы или опасения относительно обработки данных, вы можете обратиться к нам по контактам ниже.
