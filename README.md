# ZakonExpert — Снятие арестов и ограничений по исполнительным производствам

Сайт юридического сервиса [zakonexpertt.kz](https://zakonexpertt.kz) по снятию арестов с банковских счетов, карт, авто и имущества в Казахстане. Работа с ЧСИ, нотариальными исполнительными документами, исполнительными производствами.

## Страницы

| Страница | Описание |
|---|---|
| `public/index.html` | Главная (RU) — hero, проблемы, процесс, IIN-чекер, FAQ |
| `public/index_kz.html` | Главная (KZ/Казахский) |
| `public/services.html` | Услуги (RU) — карточки 15 услуг |
| `public/services_kz.html` | Услуги (KZ) |
| `public/contact.html` | Контакты (RU) — форма → WhatsApp |
| `public/contact_kz.html` | Контакты (KZ) |

## Технологии

- **Node.js 22 / Express** — сервер, API `/check`, SQLite-каталоги
- **Bootstrap 5.3** — базовая сетка и модальное окно
- **Vanilla JS** — клиентская логика (`main.js`, `site.js`)
- **Winston** — логирование на сервере
- **eGov SOAP API** — проверка ИИН по реестру АИСОИП
- **КГД API** — экспресс-проверка контрагента по БИН через серверный прокси

## Установка и запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env` и задайте переменные:

```bash
cp .env.example .env
# Заполните EGOV_API_KEY и KGD_API_TOKEN в .env
```

Запуск в режиме разработки:

```bash
npm run dev
```

Запуск в production:

```bash
npm start
```

Сервер доступен по адресу: `http://localhost:3000`

## Переменные окружения

| Переменная | Описание | Обязательна |
|---|---|---|
| `EGOV_API_KEY` | API-ключ для data.egov.kz (АИСОИП) | ДА |
| `KGD_API_TOKEN` | Токен портала КГД для проверки контрагента | для проверки по БИН |
| `KGD_API_BASE_URL` | Базовый HTTPS-адрес API КГД | нет |
| `GOSZAKUP_API_TOKEN` | Токен унифицированных сервисов портала госзакупок | для раздела госзакупок |
| `GOSZAKUP_API_BASE_URL` | Базовый HTTPS-адрес API госзакупок | нет |
| `PORT` | Порт сервера (по умолчанию 3000) | нет |
| `CORS_ORIGIN` | Домен для CORS в production | нет |
| `NODE_ENV` | `development` / `production` | нет |

**Важно:** никогда не коммитьте `.env` с реальными ключами.

## API

### POST `/check`

Проверяет наличие исполнительных производств по ИИН через eGov SOAP API.

**Тело запроса:**
```json
{ "iin": "123456789012" }
```

**Ответ (200):**
```json
{
  "debtorInfo": {
    "isDebtor": true,
    "details": [ /* массив строк из АИСОИП */ ]
  },
  "restrictions": []
}
```

**Ошибки:**
- `400` — ИИН не предоставлен
- `500` — ошибка eGov API или внутренняя ошибка

### POST `/api/company-check`

Формирует единый отчёт из доступных официальных источников: локальной копии
ГБД ЮЛ Министерства юстиции, КГД и портала государственных закупок. Если один
внешний источник недоступен, API возвращает подтверждённые данные остальных и
помечает отчёт как частичный.

```json
{ "bin": "260740044168" }
```

Токены КГД и Госзакупа используются только сервером и никогда не возвращаются клиенту.
Ответы кэшируются в оперативной памяти до 30 минут; запросы ограничены по IP.

### GET `/api/company-suggest?q=...`

Возвращает до восьми подсказок из локальной официальной базы по БИН, названию
или руководителю. Контакты и персональные идентификаторы в ответ не включаются.

## Что нельзя трогать

- ID элементов: `search-form`, `iin`, `search-button`, `loading-container`, `error-message`, `results`, `debtors-table`, `restrictions-table`, `debtorDetailsModal`
- Маршрут `POST /check` и его API-контракт
- Статическая раздача `public/`
- Функции `checkDebtorViaApi`, `asyncHandler` в `server.js`

## Деплой

Сервер запускается командой `npm start` (Node.js 22.5+). На хостинге Plesk —
через менеджер Node.js приложений. Версия 22 требуется для встроенного
`node:sqlite`. Убедитесь, что переменная `EGOV_API_KEY` задана в настройках
окружения хостинга (не в коде). Там же задайте `KGD_API_TOKEN` и
`GOSZAKUP_API_TOKEN`, затем перезапустите Node.js-приложение.

Актуальный статус и порядок подключения источников описан в
[`docs/OFFICIAL-DATA-CONNECTIONS.md`](docs/OFFICIAL-DATA-CONNECTIONS.md).

При ограниченном диске используйте `npm run storage:audit` и инструкцию
[`docs/PLESK-STORAGE.md`](docs/PLESK-STORAGE.md). Файловые логи по умолчанию
отключены; при `FILE_LOGS_ENABLED=true` они ограничены ротацией.

Каталог организаций объединяет официальный реестр и дополнительные контакты
в `data/companies.sqlite`. Порядок импорта, проверка места и откат описаны в
[`docs/ORGANIZATION-DATA-MIGRATION.md`](docs/ORGANIZATION-DATA-MIGRATION.md).

## Безопасность и приватность

- ИИН в логах маскируются: показываются только первые 4 цифры
- API-ключ хранится в переменной окружения (не в коде)
- Персональные данные не сохраняются сервером
- helmet, compression, CORS ограничение в production
