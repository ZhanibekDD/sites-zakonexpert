# data/ — таблицы для белого продвижения (Этап 3)

## link-building-targets.csv
19 реально проверенных площадок на дату аудита (не 50 — по прямому требованию задания "не выдумывать площадки"; лучше меньше, но настоящих). Часть проверена через прямой WebFetch (см. `notes`), часть — только через WebSearch с пометкой в `notes`, что нужна ручная перепроверка перед подачей заявки. `status` пустых значений не имеет смысла — все строки на старте имеют статус `research`, менять вручную по мере работы.

`priority`: high / medium / low — по колонке в самой таблице, основано на польза/риск из `docs/WHITE-HAT-LINK-BUILDING-STRATEGY.md`.

## outreach-tracker.csv
Пустой шаблон с заголовками — реальные контакты появятся по мере фактического аутрича, придумывать даты и контакты нельзя.

Допустимые значения `status`: `research`, `ready`, `contacted`, `replied`, `negotiation`, `published`, `rejected`, `follow_up`, `removed`.

## keyword-opportunities.csv
Структура и логическая привязка запросов к страницам сайта заполнены (это можно сделать из знания структуры сайта). Колонки с реальными данными спроса (`estimated_demand`, `current_position`) **оставлены пустыми** — у агента нет доступа к Яндекс.Wordstat/Google Search Console/Keys.so с авторизацией пользователя, а обходить авторизацию запрещено напрямую заданием. Жанибеку нужно вручную выгрузить данные и заполнить эти колонки.
