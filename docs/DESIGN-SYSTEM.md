# Дизайн-система ZakonExpert (Этап 14.2)

Файл: `public/css/design-system.css`. Подключён **первым**, до `landing.css`/`legal.css`/`news.css`/`style.css`, на всех страницах (39 статических `public/*.html` + оба общих EJS-layout'а `views/news/layout.ejs`, `views/laws/layout.ejs`, что покрывает все динамические страницы).

Это дополняющий, не заменяющий слой: старые CSS-файлы продолжают работать как раньше (см. `docs/DESIGN-UX-AUDIT.md` — на сайте 3 параллельные цветовые системы). Полная миграция всех компонентов на новые переменные — отдельная постепенная работа, не одномоментная замена (риск сломать продакшен слишком высок для одного захода).

## Цвета

| Переменная | Значение | Назначение |
|---|---|---|
| `--color-primary` | `#12355B` | Основной синий — кнопки, ссылки, акценты |
| `--color-primary-hover` | `#0B2545` | Hover/active состояние primary |
| `--color-primary-soft` | `#EAF0F7` | Светлый фон под primary-элементами |
| `--color-background` | `#F6F8FB` | Фон страницы |
| `--color-surface` | `#FFFFFF` | Карточки, модальные окна |
| `--color-surface-muted` | `#EEF2F7` | Второстепенные поверхности (например, alt-строки таблиц) |
| `--color-text` | `#172033` | Основной текст |
| `--color-text-muted` | `#5B667A` | Второстепенный текст |
| `--color-border` | `#D9E1EC` | Границы карточек, полей |
| `--color-accent` | `#C58B2A` | Золотой акцент — **только для мелких декоративных элементов**, не для длинного текста на белом фоне |
| `--color-accent-soft` | `#FFF6E4` | Фон под accent-бейджами |
| `--color-success` | `#166534` | Успешные статусы |
| `--color-success-soft` | `#EAF7EE` | Фон под success |
| `--color-error` | `#B42318` | Ошибки, предупреждения |
| `--color-error-soft` | `#FDECEC` | Фон под error |
| `--color-info` | `#1D4ED8` | Информационные акценты |
| `--color-whatsapp` | `#166534` | Заливка WhatsApp-кнопок (тот же success-зелёный, не отдельный) |

**Правило:** не более 2 основных акцентных цветов одновременно на экране (primary + один из accent/success/error по контексту). Зелёный — преимущественно для WhatsApp и успешных статусов. Золотой — иконки, тонкие линии, бейджи, никогда — длинные абзацы текста на белом.

**Запрещено:** кислотные цвета, неон, фиолетово-синие AI-градиенты, разноцветные карточки без смысловой нагрузки, тяжёлый glassmorphism, текст поверх сложной фотографии.

## Типографика

`--font-family-base: Inter, Manrope, -apple-system, BlinkMacSystemFont, "Segoe UI", Arial, sans-serif;` — Inter первым (не подключён физически на сайте, есть только Manrope через `@font-face` в landing.css — при отсутствии Inter браузер упадёт на Manrope, что уже загружен, без доп. запроса шрифта). Новых шрифтов не подключать.

Правила из аудита (см. `docs/DESIGN-UX-AUDIT.md` п.6 — много текста <15px на сайте сейчас):
- Body: минимум 16px, line-height 1.6, цвет `--color-text`.
- H1: `clamp(36px, 5vw, 58px)` desktop / минимум 32px mobile, line-height 1.08–1.18, не длиннее 2-3 строк.
- H2: `clamp(27px, 4vw, 40px)`, line-height 1.2.
- H3: 20–26px.
- Основной текст: максимум 70-75 символов в строке.
- Не использовать: 12-14px для основного текста, выравнивание по ширине (justify), сплошной bold, CAPS LOCK, подчёркивание не-ссылок.

## Отступы и сетка

`--container-width: 1180px` — максимальная ширина контентной области (согласуется с существующим `landing.css`, где контейнер уже близок к этому значению).

## Радиусы и тени

- `--radius-small: 8px` — мелкие элементы (бейджи, теги).
- `--radius-medium: 12px` — кнопки, поля форм.
- `--radius-large: 18px` — карточки.
- `--shadow-small: 0 2px 8px rgba(18, 53, 91, 0.08)` — лёгкая тень (hover-состояния).
- `--shadow-medium: 0 10px 30px rgba(18, 53, 91, 0.10)` — карточки, всплывающие блоки.

## Кнопки (целевой стандарт для новых компонентов)

- **Основная (primary):** заливка `--color-primary`, белый текст, hover → `--color-primary-hover`.
- **Вторичная (secondary):** белый фон, граница `--color-primary`, текст `--color-primary`.
- **WhatsApp:** заливка `--color-whatsapp` (`#166534`), белый текст. Не использовать `#25D366` (стандартный WhatsApp-зелёный) с белым текстом без проверки контраста — на светлом фоне это может не дотягивать до 4.5:1, `#166534` контрастнее и уже используется как `--color-success`.

Существующие ~13 кнопочных классов (`.btn-landing`, `.btn-legal-cta` и т.д., см. аудит) не переписываются в рамках этой задачи — новые компоненты и точечные правки денежных страниц должны использовать переменные дизайн-системы напрямую или новые утилитарные классы, без ломки существующих.

## Карточки

Белые (`--color-surface`), чёткая граница `--color-border`, тень `--shadow-small` по умолчанию / `--shadow-medium` при hover, радиус `--radius-large`, внутренний отступ минимум 20px.

## Статусы

`--color-success`/`--color-success-soft`, `--color-error`/`--color-error-soft`, `--color-info` — использовать по смыслу (успех/предупреждение/информация), не декоративно. Красный (`--color-error`) — только для реальной ошибки или важного предупреждения, не для обычного результата диагностики.

## Иконки

SVG для простых иконок (уже практикуется — Bootstrap Icons подключены сайт-wide). Иконка без текста — обязателен `aria-label`.

## Таблицы

Не описаны отдельные переменные — использовать `--color-border` для границ строк, `--color-surface-muted` для чередующихся строк, `--color-text-muted` для второстепенных колонок.

## Мобильные элементы

Минимальный tap-target 44×44px для кнопок и интерактивных элементов (см. `docs/DESIGN-UX-AUDIT.md` п.10 — на сайте сейчас 13 разных breakpoint'ов без единой сетки; новые компоненты должны ориентироваться на общепринятую сетку: 480 / 768 / 1024px, не изобретать новые значения).

## Правило использования WhatsApp-кнопки

Заливка `--color-whatsapp`, белый текст, иконка WhatsApp слева от текста. Текст кнопки должен объяснять действие («Написать в WhatsApp», «Проверить документ в WhatsApp»), не быть голым «Отправить».
