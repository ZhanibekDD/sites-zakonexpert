# Content Distribution Plan — соцсигналы

⚠️ На момент подготовки этого плана в проекте не найдено ни одного подтверждённого профиля ZakonExpert в Instagram, TikTok, YouTube или Telegram (см. `docs/SEO-STAGE-3-AUDIT.md`, раздел 4). Этот план описывает, **как** распространять контент, когда профили будут созданы — сам план не создаёт и не подразумевает создание фейковых аккаунтов.

Для каждой сильной темы из `docs/EXTERNAL-CONTENT-PLAN.md` — единый набор форматов под разные площадки, чтобы не готовить контент с нуля под каждую соцсеть.

## Формат распространения одной темы

Пример темы: «Kaspi заблокировал карту: 5 шагов, что делать в первый день» (черновик — `content/external-articles/01-kaspi-zablokirovan-5-shagov.md`)

| Формат | Площадка | Содержание | CTA | Целевая страница |
|---|---|---|---|---|
| Короткий ролик (30-45 сек) | YouTube Shorts, TikTok, Instagram Reels | Диктор проговаривает 5 шагов тезисно, текст на экране | «Проверить по ИИН — ссылка в описании» | `/arest-kaspi` |
| Карусель (5-6 слайдов) | Instagram, Telegram | Один шаг — один слайд, инфографика в стиле `/gallery` | Свайп до последнего слайда с CTA | `/arest-kaspi` |
| Пост | Telegram, Facebook (если используется) | Полный текст статьи, адаптированный под площадку | Ссылка на статью/страницу | `/arest-kaspi` |
| Сторис (3-4 кадра) | Instagram Stories, WhatsApp Status | Тизер + вопрос аудитории («сталкивались с арестом Kaspi?») | Свайп вверх / ссылка в статусе | `/arest-kaspi` |

Такой же набор форматов повторяется для каждой темы из плана — меняется только тема и целевая страница (см. `docs/LINK-DESTINATION-MAP.md`).

## Приоритетные темы для первого месяца дистрибуции
1. «Kaspi заблокировал карту: 5 шагов» — самая массовая тема, высокий потенциал охвата.
2. «5 ошибок, из-за которых должники теряют деньги» — списочный формат, легко репостится.
3. «Как за 30 секунд узнать все свои исполнительные производства» — прямая демонстрация инструмента (`/` с проверкой по ИИН), хорошо конвертит в переход на сайт.
4. Региональные темы (Алматы/Астана/Шымкент) — таргетировать на локальные паблики соответствующего города.

## Правила
- Никогда не публиковать статистику или судебную практику, не сверенную по актуальному законодательству (см. пометку ⚖️ в `docs/EXTERNAL-CONTENT-PLAN.md`).
- Каждая ссылка в описании/био — с UTM-меткой по стандарту `docs/UTM-STANDARD.md` (`utm_medium=social`).
- Не публиковать реальные кейсы без прохождения чек-листа `content/case-template.md`.
- Комментарии под постами модерировать вручную — не использовать автоответчики/ботов, имитирующих живое общение (это уже смежно с «фейковыми отзывами», что прямо запрещено заданием).

## Как измерять результат
- Клики по ссылке из био/описания — через UTM (`external_campaign_visit` в аналитике, см. `docs/UTM-STANDARD.md`).
- Рост прямых заходов на целевую страницу после публикации (сравнение до/после по датам).
- Рост обращений в WhatsApp с пометкой источника (спрашивать у новых клиентов, "откуда узнали", пока нет автоматического атрибуирования по одному номеру WhatsApp).
