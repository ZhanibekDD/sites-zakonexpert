## Как устроено хранение

Сайт не копирует миллионы строк на диск хостинга. В Git хранится Brotli-сжатый паспортный каталог, а полные записи и поиск по всем опубликованным полям выполняются сервером через официальный API V4. Это сохраняет место на тарифе 3 ГБ и позволяет показывать исправления источника без нового деплоя.

API-ключ остаётся только в переменных окружения сервера. В HTML, клиентском JavaScript, URL источника, отчётах и Git его нет.

## Обновление

- полный каталог синхронизируется ежедневно в 04:20 по времени сервера;
- версия конкретного набора определяется при первом открытии и кэшируется на 6 часов;
- записи всегда запрашиваются из активной версии официального API;
- неполный проход каталога не заменяет последнюю успешную копию: запись выполняется атомарно только после проверки `processedCount >= expectedCount`.
