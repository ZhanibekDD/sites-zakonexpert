# Официальные источники проверки контрагента

Сервис остаётся бесплатным: без подписки, лимита платных отчётов, регистрации
и рекламы внутри отчёта/PDF. Данные собираются только сервером; API-токены не
передаются браузеру и не сохраняются в репозитории.

## Что уже подключено в коде

| Источник | Данные | Настройка в Plesk | Поведение без доступа |
|---|---|---|---|
| ГБД ЮЛ Министерства юстиции — data.egov.kz | БИН, наименование, дата регистрации, статус, руководитель, адрес, деятельность | `EGOV_API_KEY` нужен для обновления локальной базы | Поиск и отчёт продолжают работать по последней импортированной официальной базе |
| КГД МФ РК | Налоговый режим, НДС, задолженность, индикаторы риска, статистика | `KGD_API_TOKEN` | Отчёт показывает профиль и честно отмечает отсутствие налогового блока |
| Портал государственных закупок | Участник, договоры поставщика/заказчика, РНУ | `GOSZAKUP_API_TOKEN` | Отчёт продолжает работать без раздела закупок |

## Какие доступы нужны сейчас

1. КГД: получить `X-Portal-Token` по обращению на странице API-сервисов и
   сохранить значение как `KGD_API_TOKEN` в переменных окружения Plesk.
2. Госзакуп: запросить первичный токен унифицированных сервисов у АО «Центр
   электронных финансов». После получения сохранить как `GOSZAKUP_API_TOKEN`.
3. Перезапустить Node.js-приложение и проверить `/health`: поля `kgdApi` и
   `goszakupApi` должны иметь значение `configured`.

Токен Госзакупа действует один год. Используемые официальные методы V3:

- `/v3/subject/biin/{БИН}` — участник;
- `/v3/contract/supplier/{БИН}` — договоры поставщика;
- `/v3/contract/customer/{БИН}` — договоры заказчика;
- `/v3/rnu/{БИН}` — реестр недобросовестных участников.

## Источники без подтверждённого публичного API

Для eLicense и Депозитария финансовой отчётности в отчёте оставлены прямые
ссылки на официальный поиск. Автоматический HTML-парсинг намеренно не
используется: он нестабилен, может нарушать правила портала и не является
официальной API-интеграцией. Подключение будет добавлено после получения
документации и разрешения владельца соответствующей системы.

## Контроль качества

- Недоступность одного источника не останавливает отчёт целиком.
- «Нет данных» не трактуется как «рисков нет».
- По каждому источнику показываются статус и дата актуальности.
- В публичный ответ не попадают токены, ИИН учредителей или идентификаторы
  третьих лиц из договоров.
- Данные купленного отчёта конкурента не копируются и не перепродаются.
