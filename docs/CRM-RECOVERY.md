# CRM recovery checklist

If WhatsApp app history is lost, reconstruct what is still available before entering data manually:

1. Open the CRM. Existing website leads from `data/leads.db` are synchronized by phone number automatically.
2. Review the existing ZakonExpert Telegram notification chat for customer names/numbers and add only missing clients, promises or notes.
3. Check whether the WhatsApp Business account itself offers an existing device/cloud backup before overwriting or resetting anything further.
4. Import or enter remaining active clients and mark their current status.
5. Download a JSON backup from CRM after the recovery pass.

The CRM cannot recreate messages that existed only on a deleted local WhatsApp installation and were never backed up or delivered through the Cloud API.
