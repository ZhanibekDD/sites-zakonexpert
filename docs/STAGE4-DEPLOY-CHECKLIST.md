## Важно

Пуш ветки в GitHub — это **не публикация на сайт**. Пока PR не смёржен в `main` и сайт не передеплоен на сервере (Plesk/аналог), изменения не видны реальным посетителям. Все шаги «После деплоя» выполнять только после реального деплоя, не сразу после мержа PR.
