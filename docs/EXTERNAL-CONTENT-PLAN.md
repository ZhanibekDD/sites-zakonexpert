# External Content Plan — 30 тем для внешних публикаций

Для каждой темы: заголовок, аудитория, площадка, польза, целевая страница ZakonExpert, анкор, CTA, нужна ли юридическая проверка перед публикацией. Анкор-стратегия — см. `docs/WHITE-HAT-LINK-BUILDING-STRATEGY.md`. Темы, отмеченные ⚖️, требуют проверки актуальности норм закона перед публикацией (законодательство меняется) — не публиковать без сверки с `adilet.zan.kz` на дату публикации.

## Как использовать таблицу
1. Выбрать тему под конкретную площадку из `data/link-building-targets.csv` (совпадение по региону/тематике).
2. Проверить пункт "Проверка" — если ⚖️, свериться с `adilet.zan.kz` на актуальность нормы перед публикацией черновика.
3. Использовать `docs/outreach/guest-post-pitch.md` для питча.
4. Готовые черновики (5 штук) — в `content/external-articles/`, не публиковать автоматически, редактировать под конкретную площадку.
