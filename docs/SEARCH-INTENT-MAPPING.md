# Search Intent Mapping — почему /zakony перетягивает коммерческий трафик

## 🎯 Главная находка сессии: внутренние ссылки вели на алиасы, а не на канонические URL

При проверке `/zakony` обнаружилось, что внутренние ссылки указывали на файлы-алиасы (`/ispolnitelnaya-nadpis`, `/chsi-arest-schetov`, `/zapret-registracionnyh-deystviy`, `/grafik-platezhey`, `/spornost-dolga`), а не на канонические чистые URL (`/otmena-ispolnitelnoi-nadpisi`, `/snyatie-ogranichenii-chsi`, `/snyatie-zapreta-registracionnyh-deistvii`, `/grafik-oplaty-zadolzhennosti`, `/vozrazhenie-na-ispolnitelnuyu-nadpis`). Проверка по всему репозиторию показала — это **не только `/zakony`**, а системная проблема: **более 20 файлов** по всему сайту (включая шаблоны каталогов ЧСИ и нотариусов) ссылались на алиасы.

Оба варианта URL технически работают (алиас отдаёт тот же файл и корректно указывает canonical на чистый URL), но постоянные внутренние ссылки на алиас вместо канонической версии — это классическая причина, по которой Google может слабее доверять «правильной» странице: сам сайт своими ссылками указывает не на неё. Заменено на канонические URL во всех найденных файлах — URL не менялись, редиректы не нужны, обратная совместимость полная (проверено: старые алиасы по-прежнему отдают 200).

Источник данных: реальная выгрузка Google Search Console за 2026-06-29 — 2026-07-12 (`zakonexpertt.kz_9a3d616db90656f192f846ff.xlsx`, 26 150 строк запрос×URL×день), агрегировано напрямую из файла — цифры не взяты из пересказа, а пересчитаны заново из исходника для проверки.

## Подтверждённая проблема

`/zakony` за две недели получил **444 показа, 29 кликов, CTR 6.53%** — и подавляющее большинство запросов, которые на неё приземляются, явно коммерческие, а не информационные про "законы вообще". Примеры реальных запросов (дословно из выгрузки), которые сейчас ведут на `/zakony`, а должны вести на страницы услуг:

| Реальный запрос из GSC | Правильная целевая страница |
|---|---|
| «как снять арест наложенный судебным исполнителем в казахстане» | `/snyatie-aresta-so-scheta` |
| «арест чси», «как снять ограничение чси», «как отменить постановление чси» | `/snyatie-ogranichenii-chsi` |
| «отмена исполнительной надписи в казахстане», «отмена исполнительной надписи срок» | `/otmena-ispolnitelnoi-nadpisi` |
| «срок нотариуса на возражение», «основания для отмены исполнительной надписи» | `/vozrazhenie-na-ispolnitelnuyu-nadpis` |
| «заявление чси о снятии ареста с банковских карт», «возрождение чси шаблон на снятие ареста со счетов» (опечатка «возражение») | `/dokumenty` |
| «график платежей задолженности перед чси», «рассрочка по исполнительной надписи нотариуса через суд» | `/grafik-oplaty-zadolzhennosti` |

Для сравнения — целевые коммерческие страницы почти невидимы в поиске за тот же период:
- `/otmena-ispolnitelnoi-nadpisi` — **1 показ** за 2 недели.
- `/ispolnitelnaya-nadpis` (файл-алиас) и `/vozrazhenie-na-ispolnitelnuyu-nadpis` — **0 показов**, в выгрузке не встречаются вовсе.
- `/chsi-arest-schetov` (файл-алиас) — 0 показов;канонический `/snyatie-ogranichenii-chsi` — 81 показ, 5 кликов.

Вывод: сотни людей ищут ровно то, что должно продавать `/otmena-ispolnitelnoi-nadpisi` и `/snyatie-aresta-so-scheta`, но Google показывает им `/zakony` — общий хаб про законы, без явного CTA на разбор конкретной ситуации.

## План решения каннибализации (реализовано в этой ветке)
1. На `/zakony` — рядом с блоками про исполнительную надпись, ЧСИ, суд — добавлены прямые контекстные ссылки-CTA на `/snyatie-aresta-so-scheta`, `/snyatie-ogranichenii-chsi`, `/otmena-ispolnitelnoi-nadpisi`, `/vozrazhenie-na-ispolnitelnuyu-nadpis`, `/grafik-oplaty-zadolzhennosti` — с анкорами, которые соответствуют реальным запросам из таблицы выше.
2. Заголовки/H1 денежных страниц не менялись в этой ветке (см. `docs/LEAD-TRACKING-PLAN.md` про измерение — сначала нужно накопить данные по ссылкам с /zakony, потом уже трогать title/H1, чтобы не смешать эффекты двух изменений).
3. `/zakony` **не закрыт от индексации** — он реально получает неплохой трафик и CTR, его роль — быть хабом с быстрым переходом на нужную услугу, а не конкурировать с страницами услуг.

## Как проверить через 14 дней
1. Отправить `/zakony` на переобход в Google Search Console и Яндекс.Вебмастер (изменился контент — появились новые ссылки).
2. Сравнить показы/клики `/otmena-ispolnitelnoi-nadpisi`, `/snyatie-ogranichenii-chsi`, `/vozrazhenie-na-ispolnitelnuyu-nadpis` до/после — ожидаемо: рост показов по тем же запросам, что раньше вели на `/zakony`, по мере того как Google переоценивает релевантность после появления внутренних ссылок.
3. Проверить в GSC отчёт «Страницы» → не снизился ли трафик `/zakony` резко (это будет сигналом, что перелинковка увела слишком много веса — тогда стоит скорректировать формулировки CTA, а не убирать их).
